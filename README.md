# Acervo Acadêmico Fatec

Sistema desenvolvido para centralizar e disponibilizar os Projetos Integradores da Fatec Itaquera, permitindo a consulta e organização dos projetos acadêmicos.

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS

## Funcionalidades

Atualmente, o projeto possui:

- Tela de login
- Tela de recuperação de senha
- Modais e pop-ups de aviso
- Estrutura inicial para a Home
- Estrutura preparada para as demais telas do sistema

Como o backend ainda está em desenvolvimento, a aplicação utiliza dados e comportamentos fictícios para simular a comunicação com a API. A estrutura foi preparada para facilitar a integração com o backend real posteriormente.
